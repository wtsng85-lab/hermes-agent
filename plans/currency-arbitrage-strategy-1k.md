# 货币套利策略研究：$1,000 资金的可执行规格

> 研究日期：2026 年 6 月 11 日（续篇，正篇见 `investment-strategy-1k-research.md`）
> 本篇回应的问题：「我需要一个具体的货币套利交易策略——有风险可以接受，但长期要稳定。」
>
> 结论先行：**"货币套利"在散户语境下有三种东西。真正的无风险套利（三角套利）散户在物理上做不到；外汇套息交易（carry trade）在散户经纪商的成本结构和杠杆下是负期望；唯一在 $1,000 量级真正可执行、且结构上接近"套利"的是加密市场的资金费率套利（delta 中性）。** 本文给出后者的完整可执行规格——包括入场/退出规则、仓位、费用数学和杀死开关。真实的预期是**好年景年化 10–20%，差年景 0–5%**，不是月化 5–10%。

---

## 一、三种"货币套利"，先分清你买的是什么

### 1. 真套利（三角套利 / 抛补利率平价）——散户物理上不可行

- 三角套利的错价窗口以**毫秒**计，被高频做市商和银行自营台在你看到报价之前吃掉。2024 年一项用 Binance 高频数据的研究找到 4,879 个理论三角套利机会，**扣除手续费和流动性约束后剩余可盈利的机会数量为零**。
- 错价幅度通常不到 1 个 pip，而散户点差本身就是 1 pip 上下——**你的交易成本大于套利空间**，这在数学上就结束了。
- 抛补利率平价（CIP）偏离的套利是真实存在的机构生意，但它需要银行资产负债表、回购融资和衍生品授信——准入门槛以千万美元计。
- 卖给散户的"套利 EA/机器人"几乎全部是曲线拟合或骗局；做延迟套利的账户会被经纪商按服务条款没收利润。

**判定：放弃。不是因为风险，而是因为这个生意在物理上轮不到 $1,000 的参与者。**

### 2. 外汇套息交易（FX Carry Trade）——学术上真实，散户执行层面负期望

这可能是你听说的"货币套利"：借低息货币（日元/瑞郎）、买高息货币（墨西哥比索、巴西雷亚尔等），赚利差。诚实的数据：

| 事实 | 数据 |
|---|---|
| 学术回报（机构口径） | G10 carry 组合 2008 年金融危机前 Sharpe 高达 ~1.08；**危机后降至 ~0.25**（ScienceDirect, 2021） |
| 风险形态 | 收益分布显著负偏——"在压路机前捡硬币"（Brunnermeier, Nagel & Pedersen, NBER）。对冲掉崩盘风险后，carry 超额收益**在统计上与零无异** |
| 最近一次压路机 | 2024 年 8 月：日本央行加息 15bp + 美国就业数据走弱 → USD/JPY 三周内从 161 跌到 141.7（−12%），日经单日 −12.4%，全球约 $4 万亿日元融资仓位中 65–75% 被强制平仓（BIS Bulletin 90） |
| 散户可买的实盘验证 | Invesco DB G10 Currency Harvest（DBV），系统化 G10 carry ETF，2006 年成立——**10 年年化回报 0.47–0.69%，自成立年化约 0.04%**（SEC 年报）。机构费率、系统化执行，二十年下来约等于零 |
| 散户经纪商的隐形抽成 | 利差通过隔夜 swap 支付，经纪商加 2–3% 的 markup——4% 的利差到你手里可能只剩 ~1–3%，同一仓位不同经纪商的隔夜成本能差一倍 |
| 杠杆数学 | $1,000 @ 30:1 = $30,000 名义仓位。高息货币对单日波动 2–5% 很常见：**5% 不利波动 = −$1,500，直接爆仓**。2024 年 8 月那种 12% 的移动会发生在你赚到第一年利差之前 |
| 长期陷阱（UIP） | 高息货币长期倾向于贬值吃掉利差：土耳其里拉 2018–2024 名义利率 8–50%，但兑美元贬值 ~90%，里拉 carry 投资者以美元计大幅亏损 |

**判定：放弃零售外汇渠道的 carry。** 学术上存在的 ~3–5%/年风险溢价，在散户的 swap 抽成、点差和杠杆爆仓风险下变成负期望。机构口径下二十年的 ETF 实盘（DBV ≈ 0%）就是终审判决。

### 3. 加密资金费率套利（Funding Rate Arbitrage）——$1,000 唯一可执行的版本 ✅

这是本文推荐研究和执行的策略，下面给完整规格。

## 二、推荐策略规格：BTC 资金费率收割（delta 中性）

### 原理

永续合约没有到期日，靠"资金费率"锚定现货价：多头拥挤时，多头每 8 小时向空头付费。策略结构：

```
50% 资金买入现货 BTC  +  50% 资金开 1x 空头永续合约（等名义金额）
→ 价格涨跌完全对冲（delta ≈ 0），你的损益 = 收到的资金费 − 手续费
```

这不是方向性交易：BTC 涨你不赚、跌你不亏，你赚的是市场多头付给你的"利息"。它结构上是套利（同一资产两个市场的价差收敛），但带有下文列出的真实风险——这正符合你说的"有风险但长期稳定"。

### 真实的历史收益（必须先看这个）

| 时期 | 资金费年化（BTC，扣费前） |
|---|---|
| 2021 牛市峰值 | 短暂 40%+ |
| 2022 熊市 | 长期接近 0 甚至 **−6%**（你倒贴） |
| 2023–2025 周期均值 | **~11%** |
| 2024 年初（Ethena sUSDe 实盘） | 峰值 ~60%，全年均值 ~18% |
| 2025（sUSDe 实盘） | 4–15% |
| **2026 Q2（当前）** | **已压缩至高个位数，Messari 口径 ~4%** |

注意这条曲线讲的故事：2024 年初 60% 的年化吸引了数十亿美元（Ethena 一个协议就吸纳了几十亿）进场做同一笔交易，**两年内把收益压到了和美国国债差不多**。这就是所有真实套利的宿命——它有效，所以它消失。

### 入场规则

1. 只交易 BTC（流动性最深、强平风险最低的标的）。
2. **仅当 7 日移动平均资金费率年化 > 8% 时建仓**（数据看 CoinGlass / The Block 的 BTC funding 页面）。低于 8% 时不值得为这点超额收益（相对 ~4% 的国债）承担交易所风险——钱留在 HYSA/国库券里等。
3. 建仓：50% 买现货，50% 作为保证金开 **1x（不加杠杆）** 等名义空单。永远不用 2x 以上——空腿杠杆是这个策略炸号的第一原因。
4. 现货和合约放在**同一家交易所**（消除两边价格瞬时偏离导致的单边强平）。

### 退出规则（杀死开关，提前写死，不临场决定）

- 资金费率**连续 3 天为负** → 全部平仓，资金回 HYSA/国库券，等下一个窗口。
- 交易所出现任何提现延迟/暂停传闻 → 立即平仓提现，宁可错杀。
- 空腿保证金率触及 50% → 减仓。设好警报。
- 每季度复评：若 7 日均费率年化持续 < 8% 超过一个季度，承认窗口关闭。

### 费用与收益数学（$1,000，诚实版）

- 开+平一轮 = 4 条腿（买现货、开空、卖现货、平空），taker 费约 0.05–0.07%/腿 ≈ **每轮 $2–3**。
- 按 2023–25 周期均值 11% 年化、一半仓位收费（空腿名义 $500 收费率，但对冲组合整体口径约等于全仓 5–6%）：**约 $55–110/年 ≈ $5–9/月**。
- 好窗口（费率年化 20%+ 时段满仓运行）：$15–20/月。
- **这就是这个策略在 $1,000 上的真实产出量级。** 它和报告正篇的结论在数字上殊途同归。

### 风险清单（每一条都有尸体）

1. **交易所倒闭**：FTX 上做这个策略的人现货+保证金一夜归零，对冲救不了你——你对冲的是价格，不是托管方。只用头部交易所，单一交易所敞口 ≤ 总资产 50%。
2. **负费率期**：2022 年式的熊市里这个策略连续数月倒贴。这就是退出规则第 1 条的由来。
3. **强平风险**：1x 空单在 BTC 单日 +20% 的暴动里保证金也会吃紧（2024 年发生过多次）——这是只用 1x、留足保证金的由来。
4. **"稳定收益"包装品的尾部**：UST/Anchor 当年承诺"稳定 20%"，2022 年 5 月三天归零 $400 亿。Ethena/sUSDe 是这笔交易的合法包装版，但你持有的是协议的对手方+托管+脱锚风险，不是存款。
5. **合规**：美国用户无法合法使用 Binance/Bybit 的永续合约。美国境内的受监管替代（Coinbase/Kraken 的期货产品）费率结构不同且选择有限——**如果你在美国，被动版（见下）可能是唯一现实路径，且需自行确认产品对美国人的可用性**。

### 两个执行版本

| | 主动版（自己跑） | 被动版（持有产品） |
|---|---|---|
| 操作 | 上述规格手动执行 | 持有 sUSDe 等 delta 中性收益稳定币 |
| 当前收益 | 跟随费率，目前 ~4–8% | 2026 Q2 约 4–9% |
| 多出的风险 | 你自己的执行失误 | 协议/智能合约/脱锚风险 |
| 适合 | 想学市场微结构的人 | 想省事的人 |

**建议起步**：先用 $200–300 跑主动版 2–3 个月当学费，记录每一笔的实际净收益 vs 理论费率——这个差值（执行损耗）会教给你比任何文章都多的东西。其余资金留在正篇的配置里。

## 三、期望管理：为什么"长期稳定"和"月化 5%"不能同时成立

你要求的"有风险但长期稳定"，资金费率套利是市场上最接近的东西——但它稳定时的产出是**年化 4–15%**。月化 5% 出现过（2024 年初），但正因为它出现了，数十亿美元在 18 个月内把它消灭了。这不是悲观，是套利的定义：**套利收益与参与资金量成反比，而你永远不是第一个发现的人。**

一句话校准：
- 真套利：无风险 → 轮不到你（毫秒战争）
- carry trade：有风险 → 散户成本结构下负期望（DBV 二十年 ≈ 0%）
- 资金费率套利：有风险、可执行 → **年化 10% 量级，不是月化 10%**
- 承诺"稳定月化 5%+"的"套利团队/量化群" → 100% 是骗局（见正篇第三节）
